swap_vert

Column Sorting

Click any column header to cycle Desc → Asc → None. Pre-sort via preSortDirection.

filter_alt

Column Filters

Text, numeric range, currency, date range, boolean, single-select & multi-select overlays.

view_column

Column Visibility

Show or hide any column at runtime with hideColumn(key) / showColumn(key). Build your own picker UI.

width_normal

Column Resizing

Drag the right edge of any header to resize. Persists per session. Reset with resetColumnWidths().

push_pin

Sticky Columns

Pin columns to the left ([sticky]="true") or right ([stickyEnd]="true") edge while the center scrolls.

expand_more

Expandable Rows

Master-detail accordions. Programmatically expand/collapse all via expandAllRows() / collapseAllRows().

checklist

Row Selection

Per-row checkboxes with selectAll, indeterminate state. Disable individual rows with isRowSelectable.

drag_indicator

Drag & Drop Reorder

CDK-powered row reordering. Toggle with the DnD button above.

speed

Virtual Scroll

CDK virtual scroll renders 5,000+ rows with a tiny DOM. Toggle to see the difference.

travel_explore

Seek to Row

Jump to any row index — even un-fetched pages — via scrollToRow(index).

download

CSV Export

Zero-dependency exportToCsv() utility with custom formatters and filename.

accessibility

Keyboard & a11y

Focusable rows with tabindex, aria-selected, Space/Enter keyboard triggers.
